# RR3 compatibility fixtures

`corpus.json` is the machine-readable contract for the deterministic EPUB and PDF files generated by `tests/e2e/compatibility-fixtures.ts`.

The fixtures contain only synthetic text and structures created for this repository. They are not copied from private books or third-party publications. Supported and degraded fixtures must open through the real personal reader routes; rejected fixtures must fail before persistence; bounded PDF fixtures must resolve to either ready or an explicit error without hanging.

See `docs/RR3_PUBLICATION_COMPATIBILITY.md` for the support, security, resource, and evidence boundaries.
