# Privacy, Surveillance, and Persecution

Mission organizations often work with information that can become dangerous in the wrong hands.

Names of believers.

Locations of churches.

Travel patterns.

Religious affiliation.

Contacts in restricted regions.

Field reports.

Prayer requests.

AI systems create new pressure to centralize and process such data.

A model can summarize reports more easily if every report is uploaded.

A search assistant works better when all organizational documents are indexed.

A strategy system becomes more powerful when it contains detailed profiles.

The technical incentive is integration.

The security incentive may be separation.

Christian organizations should therefore practice data minimization.

Do not collect information merely because it might become useful.

Do not retain sensitive information indefinitely.

Do not centralize data whose combined exposure would reveal vulnerable networks.

Do not upload field information to external AI providers without understanding retention and access policies.

Persecution changes the risk calculation.

A convenience feature in one country may become a security vulnerability in another.

Facial recognition, automated translation, network analysis, and large-scale surveillance can help governments identify communities and relationships.

Missionaries should assume that sophisticated monitoring will become cheaper.

Operational security must adapt.

This does not mean abandoning digital tools.

It means designing for threat models.

A low-risk church administration system can prioritize convenience.

A system containing underground-church identities should prioritize compartmentalization, encryption, and minimal data.

AI should not receive information simply because it can process it.

Some data are more useful uncollected.

Christian care for persecuted believers requires restraint.

The strongest database is not always the safest ministry.

[^1]: Threat models should consider not only current access policies but also future breaches, subpoenas, provider changes, and data correlation across systems.
