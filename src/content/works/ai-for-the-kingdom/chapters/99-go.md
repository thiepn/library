# Go

The final word of this book is not automate.

It is not optimize.

It is not scale.

It is not generate.

It is go.

Go to the nations.

Go learn languages.

Go listen to people.

Go make disciples.

Go build useful things.

Go translate.

Go teach.

Go serve churches.

Go strengthen local leaders.

Go where the market does not care to go.

Go where the Church is weak.

Go where Scripture is not available.

Go where people have never heard clearly about Christ.

Use every faithful tool that helps.

Learn artificial intelligence.

Understand its limits.

Build wisely.

Protect people.

Tell the truth.

Refuse synthetic substitutes for Christian responsibility.

And remember that the most important missionary technology remains a disciple willing to obey Jesus.

The tools will change.

The mission will not.

Go.

[^1]: Matthew 28:18–20; Acts 1:8.
