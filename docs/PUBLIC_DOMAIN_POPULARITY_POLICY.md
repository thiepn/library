# Public-domain popularity policy

The autonomous public-domain importer is popularity-first.

1. Current Project Gutenberg download popularity is the primary acquisition ordering when live popularity data is available.
2. Literary/curation score is a secondary ordering signal, not a substitute for popularity.
3. Germany-oriented fail-closed rights screening remains mandatory for authors, translators, editors, illustrators, and other protected contributors.
4. Existing logical works are deduplicated across alternate Gutenberg editions.
5. If live popularity data is unavailable, the complete official Gutenberg catalog and curated shelves provide the durable fallback.
6. A popularity outage must never weaken rights, EPUB, R2, CI, or deployment verification gates.
