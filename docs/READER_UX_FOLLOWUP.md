# Reader UX follow-up

This focused post-RR7 change removes the rendered hosted EPUB/PDF format switch, makes the reflowable EPUB reader the canonical general reading entry whenever EPUB is available, and adds desktop wheel/trackpad page turns in paginated mode.

PDF remains independently available from Library/book surfaces with its own persisted progress. Scrolled EPUB mode keeps native scrolling; wheel events are only intercepted for fine-pointer desktop paginated reading.
